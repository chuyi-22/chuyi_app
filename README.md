# 初一 · 好好生活

一个只给自己用的学习 / 运动 / 生活管理小站。奶油手账风，数据全部存在本机浏览器里，不联网、不登录。

## 启动

```bash
npm install     # 第一次运行
npm run dev     # 开发模式，打开 http://localhost:5173
```

手机上用：电脑和手机连同一个 Wi-Fi，启动后终端会显示局域网地址（如 `http://192.168.1.8:5173`），手机浏览器打开即可。iOS Safari / Android Chrome 里选「添加到主屏幕」，就有了全屏图标。

## 第一版包含

| 页面 | 能做什么 |
|---|---|
| 总览 | 今日完成率、学习/运动/习惯进度、今日待办、最近复盘入口 |
| 今日 | 按天记录任务，分学习/运动/生活/工作，勾选完成，可补记前后几天 |
| 计划 | 学习、运动两套总计划，每周目标次数，点 +1 记录一次，跨周自动归零 |
| 课表 | 网格 / 列表两种视图，周一至周日 × 11 节（带每节起止时间），列头显示本周日期；点空白格直接加课，可记教室和老师，时间重叠自动标「冲突」 |
| 习惯 | 习惯清单 + 最近 7 天打卡点，显示连续天数，支持补卡 |
| 复盘 | 每日心情 + 做得好的 / 没做到的 / 原因 / 下一步，可回看历史 |

## 数据说明

数据存在浏览器的 IndexedDB 里（数据库名 `chuyi`）。

- 换浏览器、换设备不会同步
- **清除浏览器数据 / 无痕模式会丢失记录**
- 后续版本会加「导出 JSON / 导入 JSON」做手动备份

安装后第一次打开会生成几条示例计划、习惯和任务，可以直接删掉换成自己的。
